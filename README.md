# Football Tweets Analyzer

Football Tweets Analyzer is a Python project designed to analyze and summarize tweets related to football (soccer). The project gathers relevant data from Twitter, processes it, and provides insights such as sentiment analysis, keyword extraction, and tweet summarization. This tool is aimed at football enthusiasts, analysts, and researchers interested in understanding the public sentiment and trends in football-related discussions on Twitter.

## Features

- **Sentiment Analysis**: Analyzes the sentiment of tweets to determine whether they are positive, negative, or neutral.
- **Keyword Extraction**: Identifies and extracts key topics and hashtags from tweets.
- **Tweet Summarization**: Provides summaries of tweets to quickly understand the main points of discussion.
- **Reports**: Generates detailed reports based on the analyzed data, helping users track changes and trends over time.

### Steps

1. Clone the repository:
   ```bash
   git clone https://github.com/MaciejSzczypek/football_tweets_analyzer.git
   ```
2. Navigate to the project directory:
   ```bash
   cd football_tweets_analyzer
   ```
3. Checkout the `refactor-04-2025` branch:
   ```bash
   git checkout refactor-04-2025
   ```
4. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

To run Football Tweets Analyzer, use the following command:
```bash
python main.py
```
